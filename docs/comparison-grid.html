The FactsPack Evolution

A side-by-side architectural analysis comparing the v0.2 foundation, the expected v0.3 proposals, and the final hardened tri-agent outcome.

Before · v0.2

Baseline Foundation

The initial release format focused on token compression, but was exposed to critical contract defects and attention lookup penalties.

Core Architecture

  • Positional Rows (-): Tab-separated cells, eliminating JSON key replication.
  • Dictionary Interning (@): Heavy strings like file paths are mapped once at the top of the pack.
  • Unsecured Integrity Trailer: Optional SHA-256 validation; only triggers if the trailer line is parsed.

Defects & Vulnerabilities

  • The Tab-Space Gap: Worked examples in the spec used alignment spaces instead of tabs. The parser split strictly on tabs, breaking copies of the example.
  • Diff Count Contradiction: Diffs set rowCount header to 0, but trailer demanded matching decoded edit lines (e.g. 2), causing strict decoder crashes.
  • Bypassable Trailer: A truncated pack with no trailer was silently accepted as a legacy v0.1 file instead of being rejected.
Vulnerability Dataflow: A truncated pack stream loses the trailer entirely. The v0.2 parser skips the check and falsely returns success.

Cognitive Attention Drag

  • Long-Range Indirection: High interning tables put dictionary keys far away from referrers, degrading LLM attention lookup accuracy.
  • Delta Churn: Symbol IDs mapped by coordinate line numbers (path#name@line) churn on simple top-of-file edits, bloating diff commits.
Expected · v0.3 Draft

Optimistic Proposals

The consensus draft added features rapidly to solve RAG traversal issues, but introduced unmeasured estimates and type risks.

Proposed Features

  • Graph Schema Grounding: Emitting a machine-readable graph structure (; gschema) to anchor text-to-cypher queries.
  • Logical Types: Machine-readable column annotations to clarify data cells for agents.
  • Adjacency Sorting: Sorting edge listings by node source and PageRank to help attention-heads traverse connections.

Vulnerabilities & Over-Reaches

  • Fabricated Calculator: Promoted unmeasured projections (e.g. "+15% for incident ordering", "+12% for communities") as precise engineering facts on the UI.
  • Lite Monikers Mutation Risk: Proposed using oxc/tree-sitter Lite monikers as mutation keys in delta chains, risking corrupting symbols due to collision errors.
  • XML Shielding Illusion: Stated XML tag wrappers made LLM inputs "Bulletproof", ignoring that cells can contain closing tags.
Collision Dataflow: Heuristic Lite monikers omit scopes and signatures. When a duplicate name collides, a destructive edit mutates the wrong symbol.

Integration Gaps

  • Process AGPL Bypass: Claimed process boundary wrapping escaped the copyleft rules of the AGPL-3.0, representing a legal conclusion as engineering fact.
  • Unpinned Determinism: Left float precision and platform path variations (Windows vs POSIX) unpinned.
Outcome · Reconciled

Hardened Reality

A strictly gated roadmap. Foundation defects are fixed first, and feature additions must prove their token and accuracy savings under P0.1.

Gate 0: Core Repair

  • Tab-Exact Fixtures: Re-generated spec examples from actual tab-separated bytes.
  • Disentangled Counts: Differential patches carry a Monotonic 0 header sentinel; trailer counts physical changes.
  • Strict Profiles: The decoder checks for header settings and throws on truncated packs omitting trailers.

Gate 1: determinism & Limits

  • Strict Path Normalization: Replaces Windows \ with POSIX / before dict allocation to guarantee reproducible hashes.
  • Ceilings & Memory boundaries: Decoder limits dictionary entries and table lengths to block denial-of-service payloads.
  • Deep Round-Trip Oracle: Replaced the lossy oracle with a byte-deep validation suite.
Determinism Pipeline: Path inputs are normalized and alphabetized. The stream is evaluated by a bounded parser checking limits and trailers.

Reworked Strategic Features

  • P0.1 Code Benchmark: Validates real-world token/accuracy savings privately before publishing claims (complying with R5).
  • Lite Monikers as Navigation Hints: marking heuristic tokens as non-authoritative. Destructive deletes/replaces require SCIP identifiers (Gate 4).
  • GSchema & Types Scoped: ; types line limited to storage specials. Graph summaries are kept off the hashed wire to preserve determinism.
